# 🐾 Tamagotchi – Virtuelles Haustier

![Processing](https://img.shields.io/badge/Processing-4.x-006699?style=flat-square)
![Language](https://img.shields.io/badge/Language-Java-ED8B00?style=flat-square)
![Status](https://img.shields.io/badge/Status-In%20Entwicklung-2ea44f?style=flat-square)

Ein interaktives virtuelles Haustier, entwickelt im Rahmen des Moduls **Student's Lab (SLAB)** mit **Processing (Java)**.  
Ziel des Projektes ist es, ein Haustier zu erschaffen, dessen Wohlbefinden von der Pflege des Nutzers abhängt – kombiniert mit eigenen Processing-Mechaniken, Grafiken und Minispielen.

---

## 🎯 Features & Roadmap

### Phase 1: Minimalziele (Basis)
- [ ] Grundbedürfnisse des Tieres (**Nahrung**, **Hygiene**, **Energie**)
- [ ] Zeitabhängiges Absinken der Werte & Zustandslogik
- [ ] Maussteuerung und einfache Benutzeroberfläche (UI)
- [ ] Erste interaktive Processing-Mechaniken

### Phase 2: Gameplay & Processing-Erweiterungen
- [ ] Minigames zur Beschäftigung des Haustiers
- [ ] Emotionen & sichtbares Feedback des Tieres
- [ ] Zeit-Zyklus, Alterung & dynamische Farbanpassung
- [ ] „Kill-Score“ (Scoreboard mit Überlebenszeit, Tieranzahl etc.)

### Phase 3: Optionale Ideen (Ausblick)
- [ ] Auswahl verschiedener Tierarten mit eigenen Bedürfnissen
- [ ] Bekleidung / Accessoires für das Haustier
- [ ] Anpassbare Umgebung / Hintergründe (z. B. Wald)

---

## 🚀 Projekt lokal starten

1. Lade die aktuelle Version über **Code → Download ZIP** herunter (oder klone das Repository).
2. Stelle sicher, dass **[Processing 4](https://processing.org/download)** installiert ist.
3. Öffne die Hauptdatei `Tamagotchi/Tamagotchi.pde` in Processing.
4. Klicke oben links auf **Run (▶)**, um das Spiel zu starten.

---

## 📂 Projektstruktur

```text
├── Tamagotchi/        # Hauptprogramm (Processing-Sketch & data-Ordner)
└── Tests/             # Isolierte Einzel-Tests der Gruppenmitglieder
```

*(Hinweis: Jeder Branch im Repository dient aktuell als separater Arbeitsbereich für ein Gruppenmitglied, bevor fertige Features in `main` zusammengeführt werden.)*
